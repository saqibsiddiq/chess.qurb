# Reference data

Canonical derived assets shared by the dataset pipeline (`dataset/`,
`tools/`) and the app (`app/`). Nothing here is a primary source — it's
all generated from `data/clean/corpus_unique.jsonl` and can be
regenerated at any time.

## `opening_book.json`

Generated by `tools/dataset/build_opening_book.py`. Maps a position key
(a FEN's first 4 fields) to the list of UCI moves that recurred across at
least `--min-games` (default 10) distinct real games in Chesy's own
corpus within the first `--max-move-number` (default 10) full moves.

This is a corpus-frequency heuristic, not a licensed opening-theory
database — see `ml/specs/classification_policy.md` for what "Book" means
in Chesy's classifier and why this is documented as an approximation.

`dataset/src/classify.py` reads this file directly (the dataset pipeline
must not depend on an app asset). `app/src/data/openingBook.json` is a
generated bundled copy for Vite to import — regenerate both together via
`tools/dataset/build_opening_book.py`'s default `--app-copy` behavior,
don't hand-edit the app copy separately.
